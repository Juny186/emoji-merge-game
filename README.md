# 合成大表情 🤩

相同的表情撞在一起，越合越大！一个纯前端的物理合成小游戏（合成大西瓜玩法）。

## 玩法

- 点击/触摸游戏区域投放表情
- 两个**相同**的表情碰到一起，合成更大一级的表情
- 表情堆过顶部警戒线持续不落下 → 游戏结束
- 合成等级越高得分越多，看看你能不能合出 🪐

**合成路线：**

😴 → 🙂 → 😊 → 😄 → 🤣 → 🤩 → 🥳 → 🤯 → 👑 → 🐉 → 🪐

## 特性

- Matter.js 物理引擎，自绘 Canvas 渲染
- 移动端 / 桌面端自适应
- 合成粒子特效、飘分、震屏、音效（可关闭）
- 最高分本地保存（localStorage），零后端依赖

## 本地运行

任意静态服务器即可，例如：

```bash
py -3 -m http.server 8000
```

然后打开 http://localhost:8000

## 技术栈

原生 HTML / CSS / JavaScript + [Matter.js](https://brm.io/matter-js/)（已内置于仓库，无需 CDN）
